RELEASE_METADATA

This document mirrors RELEASE_METADATA.toml.
It is informative only. The authoritative release metadata is RELEASE_METADATA.toml.

------------------------------------------------------------

What RELEASE_METADATA.toml contains

RELEASE_METADATA.toml records the authoritative release identity of
SLML v0.1 (hawkseye). It is populated at freeze time.

Fields populated at freeze:
- tag: the Git tag applied at release
- commit_hash: the exact commit frozen as the release
- freeze_timestamp_utc: the UTC timestamp of the freeze
- release_hash: the SHA-256 hash of the full normative artifact set

Fields populated before freeze:
- version, codename, canonical_release_root, hash algorithm,
  required_normative_artifacts list, authority model declaration

------------------------------------------------------------

Why it exists

RELEASE_METADATA.toml is the single artifact that binds all release
identity fields together. A compliance claim that references
SLML/0.1(hawkseye) is traceable to this file and through it to
the exact frozen artifact set.


```toml[meta]
standard_name = "SLML"
artifact = "release_metadata.toml"
governance_version = "1.0"
metadata_schema_version = "1.0"
status = "NORMATIVE"

[release]
version = "v0.1"
codename = "hawkseye"
canonical_release_root = "branch:release-v0.1--hawkseye"

# Populated at freeze time
tag = "<TO_BE_SET_AT_FREEZE>"
commit_hash = "<TO_BE_SET_AT_FREEZE>"
freeze_timestamp_utc = "<TO_BE_SET_AT_FREEZE>"

[hash]
algorithm = "SHA256"
encoding = "hex_lower"
canonicalization = true
release_hash = "<TO_BE_SET_AT_FREEZE>"

[immutability]

[validator]
```
