What normative examples are

Normative examples define the conditions under which a specific
class of workflow is permitted to be ADMISSIBLE under SLML v0.1.

They are not illustrations. They are binding conditions.

------------------------------------------------------------

Closed lyric evaluation workflow

A lyric evaluation workflow may be ADMISSIBLE if and only if:

- No external corpora are used
- No cross-session learning occurs
- User lyrics are not retained after the session
- No third party benefits from the workflow
- Consent is explicit and time-bounded
- Inconvenience is explicitly declared
- User-directed obligations are restricted to informational disclosure

If any of these conditions is violated in reality,
the manifest must be updated to reflect that violation.
If the manifest is not updated, the compliance claim becomes false.
